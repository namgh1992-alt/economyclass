# 우리 반 경제 교실 · 온라인 서버

학교 공용 패드에서 여러 기기가 동시에 쓰는 학급 경제 교실입니다.
Cloudflare Workers(무료)에서 돌아가고, 반마다 전용 저장소(Durable Object) 하나에 기록이 쌓입니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `public/index.html` | 화면 (선생님·학생이 여는 페이지) |
| `src/worker.js` | 서버: 반 목록, 로그인, 권한 확인, 수업 시작/끝, 활동 기록 |
| `src/core.js` | 서버와 화면이 함께 쓰는 동기화·권한 규칙 |
| `wrangler.jsonc` | Cloudflare 배포 설정 |
| `package.json` | 배포 도구(wrangler) 버전 |

## 처음 배포하기

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다 (`public`, `src` 폴더 구조 그대로).
2. Cloudflare 대시보드 → **Workers & Pages → Create → Import a repository** 에서 GitHub를 연결하고 이 저장소를 고릅니다.
3. 프로젝트 이름은 `class-economy`, 배포 명령은 `npx wrangler deploy` 그대로 두고 **Deploy** 를 누릅니다.
4. 1~2분 뒤 `https://class-economy.(내 이름).workers.dev` 주소가 생깁니다.

## 고칠 때

GitHub 저장소의 `public/index.html` 을 새 파일로 바꿔 올리면 Cloudflare가 자동으로 다시 배포합니다.

## 지켜지는 규칙 (서버가 확인)

- 첫 화면에서 바로 들어갑니다. 선생님은 학교 + 반 + 선생님 비밀번호, 학생은 수업 코드 + 번호 + 자기 비밀번호(숫자 4자리)입니다.
- 학생은 처음 들어올 때 비밀번호를 직접 정합니다. 선생님은 관리자 탭의 '학생 비밀번호'에서 확인하고 바꾸거나 지울 수 있습니다.
- 학생은 수업이 열려 있는 동안에만 들어올 수 있고, 수업을 끝내면 모든 학생이 로그아웃됩니다.
- 학생은 자기 직업에 **입력** 권한이 있는 화면만 고칠 수 있고, 자기 기록(자기 통장, 자기 점수, 자기 거래)은 고칠 수 없습니다.
- 학생 패드에는 다른 학생의 사진·통장 내역이 직업 권한에 따라 걸러져서 갑니다.
- 모든 변경은 누가·언제 했는지 활동 기록에 남고, 선생님이 한 줄씩 되돌릴 수 있습니다.
- 선생님 비밀번호와 시스템 관리자 비밀번호는 서버에 암호화되어 저장되고, 여러 번 틀리면 잠깁니다. 학생 비밀번호는 선생님이 확인할 수 있게 서버에 따로 보관되며 학생 화면으로는 보내지 않습니다.
- 시스템 관리는 첫 화면 맨 아래 '시스템 관리' 링크에서 엽니다.
